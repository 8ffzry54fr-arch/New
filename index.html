Resumo com IA (Claude)

O resumo automático é grátis e feito no próprio celular. O resumo com IA fica mais bem escrito, mas precisa de uma chave da API da Anthropic (console.anthropic.com), que é paga por uso.

Atenção: ao usar o resumo com IA, o texto do livro é enviado à Anthropic para ser resumido. A chave fica salva só neste aparelho.
